Requires Android 11 or newer on an ARM64 phone.
No Visual Studio, .NET installation, USB debugging or PC connection is needed to run it.

1. Copy the APK and JSON to your phone's Downloads folder using USB or Quick Share.
2. Open GrimList-Android-Test.apk in the phone's Files app.
3. If Android asks, allow installation from this Files app, then tap Install.
4. Open GrimList.
5. Open the top-right menu > Manage data. Select BSData community and
   Points + datasheets, then Choose local source.
6. Select GrimList-Library.json, review the preview, then tap Apply update.
   Full-library preview took about 77 seconds in the latest Release emulator check.
   Physical-phone timing has not yet been measured.
7. Open the menu > New army. Choose faction, detachment, name and points, then Create army.
8. Add a unit. Tap its roster card, then Equipment to edit its wargear.
   Others appears before every Allies faction section in both the unit browser and roster.
   Champion and squad equipment use the same groups as Windows.
   Squad upgrades show individual maxima and shared special-weapon capacity.
   Counters replace standard equipment automatically; dimmed controls have reached a limit.
   Highlighted single-model choices are selected.
9. Return to the roster to see selected upgrades and their costs.
   Hold a unit card for Delete/Duplicate, or tap its X to remove it.
   Leader/Support attachment controls are on Datasheet, above Abilities.
   Universal weapon rules such as Lethal Hits have their own Keywords section.
   Unit size is on Equipment; the former Manage tab has been removed.
10. Committed changes save automatically. Close and reopen the app to test restoration.

You can instead export your current library from Windows using Export dataset
and import that JSON. Dataset JSON contains the library, not Windows saved armies.
