Scope
Matching Windows and Android versions contain the current army builder, battle
tracker, bug-report workflow, compact version-3 battle exchange and QR display.
Outgoing exchanges share player name, faction and disposition plus matching IDs;
players discuss armies in person. Secondary choices are local, scores do not sync,
and phone scanning uses an external QR scanner/custom app link.
Android round swipes are on the fixed heading, outside the vertical scroll view.
That fix was confirmed by the user on 0.2.19 and is retained unchanged here.
No live rules/data refresh was performed for this app release.

Agent/build handoff
AGENTS.md now records architecture, sources/provenance, user decisions, protected
storage, toolchain, release/testing commands, limitations and bounded build storage.
The old QR test launcher now delegates to the normal current-source launcher.
Builds reuse project bin/obj rather than creating per-task source copies. Publishing
removed older numeric Android, Windows payload and Windows installer release folders.
Only the current package is retained in each of those release channels.
Successful regression runs clean their own generated databases. MSI/app validation
now removes temporary extracted payloads and disposable user-data folders.

Regression maintenance
The initial full run passed 423 checks and found two test issues. The idempotence
assertion assumed one source row even after legitimate reference recovery; it now
compares source IDs before/after reopening and still rejects any bootstrap reload.
Three missing historical sample fixtures were restored byte-for-byte from the old
workspace ZIP. These changes affect tests/fixtures only; application packages did
not need rebuilding. Both initial and final logs are retained for transparency.

Limitations
Windows MSI is unsigned. Android uses the established development signing key.
Actual MSI install/repair/upgrade/uninstall remains unverified in this restricted
session; do those checks on an unrestricted test machine. Camera optical scanning
and broader community device coverage remain manual. This release does not claim
all game rules are current or that every bug has been found.
