Concise text roster export — 2026-10-25

into each unit block. This exposed modifier diagnostics such as Combi-bolter

Both frontends use this shared exporter; PDF roster summaries also use it.

with standard and pintle Combi-bolters selected exports one 2 × Combi-bolter
row. A Rhino with only the standard bolter selected still exports one gun.
Modifier annotations do not represent additional equipped weapons. No saved
loadouts, prices, validation rules or detailed weapon profiles were changed.
